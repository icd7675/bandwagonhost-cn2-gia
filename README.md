中国电信的海外回国有四档主流线路，从便宜到贵依次是AS4134（ChinaNet/163骨干网）、CN2 GT（Global Transit）、CN2 GIA（Global Internet Access）和最新的CTGNet。搬瓦工官方在CN2 GIA介绍页里说得很直白：163骨干网晚高峰丢包率能到30%以上，CN2 GT自2019年起也基本和163一样拥堵，只有CN2 GIA始终稳定。

对个人和小团队用户来说，CN2 GIA的实际意义是：晚高峰看YouTube不缓冲、远程SSH操作不卡顿、给国内用户访问的站点加载稳定、跑低延迟业务（游戏加速、VOIP、视频会议）不掉线。如果你只是自己挂个梯子看看资料，普通CN2 GT甚至163线路白天也够用；但凡涉及"国内用户要稳定访问"或"自己要稳定连回国内"，CN2 GIA的差距就出来了。

## CN2 GIA vs CN2 GT：别被名字骗了

很多人把CN2 GT和CN2 GIA混为一谈，其实差距不小：

- **线路优先级**：CN2 GIA是电信CN2体系里的最高等级，独立回国链路、轻负载；CN2 GT名义上是CN2，但实际承载和163差不多。
- **晚高峰稳定性**：CN2 GT晚高峰有丢包风险，CN2 GIA基本不受影响。
- **延迟**：洛杉矶CN2 GIA到国内电信平均180ms以内，CN2 GT在200ms左右且有波动。
- **三网支持**：搬瓦工洛杉矶USCA_9机房把电信走CN2 GIA（AS4809）、移动走CMIN2（AS58807）、联通走Premium（AS10099），三网都是优化线路；CN2 GT主要只优化电信方向。
